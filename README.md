# Цифровой учебно-методический комплекс: Dirpipe

## Специальность 09.02.06 «Сетевое и системное администрирование»

**Статус:** 🚧 Исследования и разработка (R&D Phase / Work in Progress)

**Dirpipe** — это экспериментальная площадка для создания иммерсивного образовательного контента по специальности 09.02.06 «Сетевое и системное администрирование». 

Проект базируется на авторской методологии адаптивного скаффолдинга (управляемого снижения дидактической поддержки) и симуляции реальных производственных инцидентов. На текущий момент ведется проектирование педагогической архитектуры комплекса и наполнение базовых методических треков.
